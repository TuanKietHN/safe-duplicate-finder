# Trình tìm tệp trùng lặp an toàn 0.2.1

Đây là bản vá phát hành cho Windows x64. Bản này giữ nguyên các hàng rào quét chỉ đọc, cách ly có thể
khôi phục và xác nhận riêng trước khi xóa vĩnh viễn.

## Thay đổi chính

- Sửa GitHub Actions Windows bị chặn vì cấu hình Tauri yêu cầu helper Runtime trước khi helper được
  biên dịch.
- Tách cấu hình đóng gói online setup khỏi cấu hình Tauri dùng cho kiểm thử và Clippy.
- Sửa Docker build sạch bị thiếu workspace member `apps/runtime-installer`.
- Nâng Rust dependency tương thích, gồm `rusqlite 0.40.2` và `sha2 0.11.0`.
- Nâng frontend lên Vite 8.2.1, Vitest 4.1.10, ESLint 10.8.1 và TypeScript 6.0.3.
- Nâng CI lên Node.js 24.18.0 LTS, `actions/checkout@v6` và `actions/setup-node@v6`.
- Thêm workflow phát hành theo tag để build NSIS, xác minh phiên bản và tải EXE/checksum lên GitHub
  Releases bằng quyền tối thiểu `contents: write`.
- Nâng image container lên Rust 1.97.1/Debian Trixie và xác minh chạy bằng user không đặc quyền với
  thư mục nguồn chỉ đọc.

## Cài đặt

Tải `safe-dedupe-setup-0.2.1-x64.exe` trong phần Assets rồi chạy bằng tài khoản Windows hiện tại.
Setup có helper native để kiểm tra, tải tiếp và xác minh SHA-256 của WebView2 khi cần.

Đối chiếu SHA-256 bằng:

```powershell
Get-FileHash -Algorithm SHA256 .\safe-dedupe-setup-0.2.1-x64.exe
```

## Kiểm chứng

- 120 kiểm thử Rust và 15 kiểm thử frontend đạt.
- Clippy, ESLint, Prettier, TypeScript/Vite production build đạt.
- Docker build và smoke test `check` đạt.
- `npm audit` báo 0 lỗ hổng; `cargo deny` đạt.

## Lưu ý bảo mật

Bộ cài hiện **chưa ký Authenticode**, vì vậy Windows có thể hiển thị cảnh báo nhà phát hành không xác
định. Hãy kiểm tra SHA-256 trong asset `release-checksums.json` trước khi chạy. Không cài nếu checksum
không khớp.
